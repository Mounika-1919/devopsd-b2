# Jenkins CI/CD Demonstration

## Experiment 1: Installation and Setup of Jenkins

### Aim
To install and configure Jenkins for software development automation.

### Procedure
1. Download and install Jenkins.
2. Start the Jenkins service.
3. Open http://localhost:8080 in a web browser.
4. Unlock Jenkins using the initial administrator password.
5. Install suggested plugins.
6. Complete the setup and open the Jenkins dashboard.

## Experiment 2: Demonstration of CI/CD Using Jenkins

### Aim
To demonstrate a basic Java application build and execution using Jenkins.

### Software Requirements
- Windows
- Java JDK
- Git
- Visual Studio Code
- Jenkins

### Procedure
1. Create a Java application.
2. Store the source code in a Git repository.
3. Configure a Jenkins Pipeline job.
4. Build the application using the Jenkinsfile.
5. Execute the application and check the console output.

### Expected Output
Hello World
CI/CD using Jenkins
Build successful!

### Result
Jenkins was installed and configured. A basic Java application was created and tested, ready for integration with a Jenkins pipeline.
